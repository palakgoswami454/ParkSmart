# Outputs

Everything here is regenerated by the pipeline; nothing is edited by hand.

| Path | Produced by | Contents |
|---|---|---|
| `metrics/training_summary.json` | `src.train` | rows per split, tuning logs, best hyper-parameters, walk-forward fold scores, fit and prediction times, interval half-widths, selected models |
| `metrics/evaluation_summary.json` | `src.evaluate` | test-period tables, segment errors, confusion matrices, FULL error counts, permutation importance, interval coverage, unseen-car-park experiment, time-of-day interval coverage (`interval_band_report`) |
| `metrics/regression_comparison_h{30,60}.csv` | `src.evaluate` | regression comparison table |
| `metrics/classification_comparison_h{30,60}.csv` | `src.evaluate` | classification comparison table |
| `metrics/per_park_errors_h{30,60}.csv` | `src.evaluate` | test MAE per car park |
| `metrics/permutation_importance_h{30,60}.csv` | `src.evaluate` | permutation importance on the test period |
| `metrics/prediction_examples_h{30,60}.csv` | `src.evaluate` | representative test predictions (10th/50th/90th/99th percentile error) |
| `metrics/eda_summary.json` | `src.eda` | every EDA number quoted in the report |
| `metrics/transfer_summary.json` | `src.transfer` | park-agnostic model on a held-out car park, and the sample-upload check |
| `predictions/test_predictions_h{30,60}.csv` | `src.train` | every model's prediction for every test row |
| `figures/eda_*.png`, `figures/eval_*.png` | `src.eda`, `src.evaluate` | report figures |
