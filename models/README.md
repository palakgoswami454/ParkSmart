# Models

Generated by `python -m src.train`. One file per forecast horizon:

| File | Horizon | Contents |
|---|---|---|
| `parksmart_h30.joblib` | 30 min | selected regressor + selected status classifier |
| `parksmart_h60.joblib` | 60 min | selected regressor + selected status classifier |
| `parksmart_transfer_h{30,60}.joblib` | 30 / 60 min | park-agnostic regressor (car-park ID hidden) used by *Test on your own data*; built by `python -m src.transfer` |

Each file is a Python `dict` saved with `joblib` (compress=3):

* `regressor`, `regressor_name` – fitted scikit-learn pipeline predicting the occupancy rate
* `classifier`, `classifier_name` – fitted status classifier (LOW / MODERATE / HIGH / FULL)
* `features`, `feature_descriptions` – the exact input columns, in order
* `park_codes`, `capacities` – car-park ID mapping and capacities
* `interval_halfwidth_90`, `interval_halfwidth_80` – single-width uncertainty range, from walk-forward residuals
* `interval_table_90` – time-of-day band half-widths actually used by the app (`src/intervals.py`)
* `trained_on`, `sklearn_version`

Load with `src.predict.load_bundle(60)`. The files were saved with scikit-learn 1.9.1; loading them with a different version may fail or warn, in which case re-run `python -m src.train`.
